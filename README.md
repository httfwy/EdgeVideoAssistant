# Edge Video Assistant

Microsoft Edge 扩展：检测当前页视频、下载直链 / HLS、可选录制，以及页面倍速。视频处理均在本地完成，不会上传内容。

## 安装

1. 安装依赖并打包：

```powershell
cd "Edge Video Assistant"
npm install
npm run build
```

2. 打开 Edge → 扩展 → 打开「开发人员模式」→「加载解压缩的扩展」→ 选择本目录下的 `dist`。
3. 若提示新权限（如下载、通知、Offscreen、标签页捕获），请允许后重新加载扩展。

## 权限用途

| 权限 | 用途 |
|------|------|
| storage | 保存任务、设置与检测结果 |
| scripting / tabs | 向当前页注入检测与倍速脚本 |
| webRequest | 嗅探页面已发出的媒体请求 |
| downloads | 保存文件到浏览器下载目录 |
| notifications | 完成后通知（可在设置中关闭） |
| offscreen | HLS 分片合并与 MediaRecorder |
| tabCapture | 标签页录制 |
| 主机权限 http(s) | 读取公开媒体地址 |

不申请 `debugger` 权限。

## 使用说明

- **检测**：打开 Popup 会自动扫描当前页。可点「刷新」。
- **下载**：MP4 等直链直接下载；HLS（m3u8）点「解析」选清晰度后再下载，保存为 `.ts`。未解析时默认最高码率。
- **DASH**：解析后展示轨道；若 MPD 提供完整文件地址可分别下载音视频，否则请改用录制。
- **录制**：标签页 / 屏幕录制输出 WebM。关闭 Popup 不中断，可在任务页查看。
- **直播**：对无结束标记的 HLS，卡片主操作为「录制」。按设置中的分段时长切分文件（`part-01.ts` 起）。**暂停后同一分段接着写**，不会立刻新开文件。
- **倍速**：Popup 芯片与页面右上角浮层同步。设置中可关闭浮层；关闭「记住上次倍率」时每次默认 1x。

## 限制

- 不支持破解 DRM、获取密钥或绕过版权保护。无法直链保存时请在个人合法访问范围内使用录制。
- HLS 简易下载输出 MPEG-TS（`.ts`），本版本不内置 ffmpeg 封装 MP4。
- 跨域分片失败时会提示改用录制。
- 不提供字幕、转码、剪辑、下载加速或多平台完整解析。

## 合规

插件只处理用户已经能够播放的公开资源地址，不发起平台破解请求。
